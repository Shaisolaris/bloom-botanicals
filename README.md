# Bloom Botanicals — Plant Shop

E-commerce plant shop with a fully working cart and checkout flow.

**[Live Demo](https://shaisolaris.github.io/bloom-botanicals/)**

WooCommerce-class storefront patterns in dependency-free HTML, CSS, and vanilla JavaScript.

## Features

- **Working cart** — add from cards or the quick-view sheet, quantity steppers in the drawer, live subtotal/shipping/total, and a free-shipping progress bar that unlocks at $75
- **Quick-view sheet** — species details, care badges (light / water / pet-safety), sale pricing, and a quantity picker
- **Category filters** — All / Statement / Easy Care / Pet Friendly chips over the product grid
- **Checkout flow** — order placement clears the cart and returns a confirmation number
- **Sale & new badges**, strikethrough pricing, hover elevation, perk strip, responsive layout down to mobile

## Structure

Single self-contained page: product catalog and cart state managed in a compact vanilla JS layer, gradient + emoji product art keeping the repo asset-free, and a warm cream/forest design system with serif display type. No frameworks, no build step, no external requests.
